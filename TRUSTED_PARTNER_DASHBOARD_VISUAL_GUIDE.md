## Color Scheme

### Status Colors
- 🟢 **Green** - Completed, Active, Success metrics
- 🔵 **Blue** - Approved, In-App payments
- 🟡 **Amber** - Pending, Daily metrics
- 🔴 **Red** - Rejected
- 🟣 **Purple** - Monthly metrics, Completion rate
- 🟠 **Orange** - POS payments
- 🟦 **Teal** - Weekly metrics, Repeat customers

### Icon Meanings
- 🎟️ Deals/Discounts
- ✅ Active/Verified
- ✔️✔️ Completed
- 💰 Money/Value
- 💵 Revenue
- 💚 Total/Success
- 💙 In-App
- 🟠 POS
- 💜 Monthly
- 🟦 Weekly
- 🟡 Daily
- 💳 Payment Methods
- 📱 Mobile/In-App
- 🏪 Store/POS
- 📋 Requests
- 👥 Customers
- 👤 Individual
- 🔁 Repeat
- 📈 Trends/Charts
- 🏆 Top/Best
- 🕒 Recent/Time
- 🔄 Refresh

## Interactions

### Refresh
- **Pull to Refresh** - Swipe down anywhere on the screen
- **Tap Refresh Icon** - In the app bar (top right)

### Navigation
- **Back Button** - Returns to Trusted Partner Home Page
- **App Bar** - Shows current page title

### Future Interactive Elements
- Tap metric cards for detailed drill-down
- Tap deal in top deals list to view deal details
- Tap transaction to view full transaction details
- Date range picker for custom time periods

## Responsive Design

### Mobile (Default)
- Single column layout
- Cards stack vertically
- Full-width components
- Scrollable content

### Tablet (Future)
- Two-column layout for metric cards
- Side-by-side revenue breakdown
- Larger chart area
- More transactions visible

### Desktop (Future)
- Multi-column grid layout
- Dashboard-style overview
- Persistent navigation sidebar
- Expanded chart analytics

## Accessibility

- ✅ High contrast colors
- ✅ Large touch targets (48dp minimum)
- ✅ Readable font sizes
- ✅ Icon + text labels
- ✅ Screen reader support (semantic widgets)
- ✅ Color-blind friendly palette

## Performance

- ⚡ Single RPC call loads all data
- ⚡ Efficient list rendering with ListView.builder
- ⚡ Pull-to-refresh for manual updates
- ⚡ Smooth chart animations
- ⚡ Optimized image loading (if logo support added)

## Error States

### Loading
- Shows centered CircularProgressIndicator
- Full-screen loading state

### Error
- Red error icon (64dp)
- Error message text
- Retry button
- Centered layout

### Empty Data
- Graceful handling of zero values
- "No data available" messages for empty lists
- Helpful guidance for new TPs

## Data Updates

### Real-Time
- Dashboard data is fetched on load
- Refresh updates all metrics
- No automatic polling (to save resources)

### Recommended Update Frequency
- On page load (automatic)
- After completing a deal (manual refresh)
- Daily check-in (manual refresh)
- Monthly review (manual refresh)
